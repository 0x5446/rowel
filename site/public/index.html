02

The exact command.
Not a summary.

Approvals arrive with the full command and diff the agent wants to run, and the reason it gave. You decide on what will actually execute — then the Mac carries on while you are still on the train.

03

The relay is blind.
By design.

Phone and Mac run a Noise IK handshake with each other, not with us. Our relay switches sealed frames it holds no key for — and an end-to-end test taps the wire and fails if a method name or a machine name ever appears in the clear. On the same Wi-Fi, there is no relay at all.

Questions

Is it free?

Yes. The app, Bridle, the relay and the protocol are all MIT-licensed and free.

Does my code leave my Mac?

Only to your own phone, end-to-end encrypted. The relay in between cannot read it, and Rowel never sends anything to an AI service — the agent runs on your Mac with the provider you configured there.

Do the phone and Mac need to be on the same network?

No. On the same Wi-Fi they talk directly; anywhere else they meet through the relay, still end to end encrypted.

Can I run my own relay?

Yes. It is in the repository, and bridle --relay wss://your.host is the whole client side.

Is it on the App Store?

It is in App Store review. Until then it is on TestFlight, and the build there is the one that was submitted. Where the release stands.

Start with Help — pairing, connection and harness problems are covered there.
