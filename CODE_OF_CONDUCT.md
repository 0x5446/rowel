# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its code
of conduct. It is linked rather than pasted so that it cannot quietly drift from
the canonical text.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

It applies to issues, pull requests, commit messages, and anywhere someone is
representing this project.

## Reporting

`rowel@novabox.ai`, subject starting with `CONDUCT`.

Be aware of what that means here. One person maintains this project, and that
person receives, investigates, and decides on reports. There is no committee and
no appeal to anyone else. If the report is about the maintainer, there is nobody
else to send it to — which is a real limitation of a one-person project, and
saying so is more useful than a process description that implies otherwise.

Reports are handled privately. What follows from one ranges from a request to
edit a comment through to a block, and the maintainer's judgement is the whole of
the mechanism.
